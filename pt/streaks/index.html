Como Funciona

Streak Counter é um calendário para as correntes que você está construindo. Duas formas de jogar: uma sequência de check-in pede um toque por dia — cada check-in estende sua corrente, e o calendário a desenha como uma linha colorida. Uma sequência de contagem progressiva só precisa de uma data de início e depois sobe para sempre, perfeita para contadores de "dias desde que parei". As duas vivem no mesmo calendário grande, cada uma com sua cor e ícone, então um bom mês literalmente se pinta sozinho. Acompanhando muitas coisas? Toque em ocultar numa sequência para tirar a linha dela da visão Todas — a sequência continua contando, seu calendário fica limpo. A visão Todas desenha até cinco linhas por vez; além disso, sequências extras viram um pequeno selo "+N" nos dias em que estão ativas, e ocultar uma faz a próxima subir para a faixa dela.

Como funciona o contador de sequências?

De duas formas. Uma sequência de check-in pede um toque por dia — cada check-in estende sua corrente, e o calendário a desenha como uma linha colorida. Uma sequência de contagem progressiva só precisa de uma data de início e depois sobe para sempre, perfeita para contadores de "dias desde que parei". As duas vivem no mesmo calendário grande, cada uma com sua própria cor e ícone.

O que acontece se eu perder um dia?

Nas sequências de check-in, a série atual quebra — mas sua melhor sequência fica guardada para sempre, então uma falha nunca apaga sua série mais orgulhosa. Esqueceu de fazer check-in ontem? Sem punição aqui: toque em qualquer dia passado no calendário para preenchê-lo. Funciona no sistema da honra, como um calendário de papel.

Qual é a diferença entre uma sequência de check-in e uma contagem progressiva?

Uma sequência de check-in é um ritual diário — você marca cada dia em que apareceu, e perder um dia zera a contagem atual. Uma contagem progressiva é automática: defina o dia em que você começou (ou parou) algo e ela conta para cima para sempre, sem manutenção. Use check-ins para hábitos que você constrói, contagens para o que ficou para trás.

Meus dados são salvos? Posso mover para outro dispositivo?

Sem conta, nunca. Suas sequências ficam salvas no armazenamento local deste navegador, então continuam aqui quando você volta — mas vivem apenas neste dispositivo e nada é enviado para lugar nenhum. Para mover ou fazer backup dos seus dados, use Exportar para baixar um arquivo JSON e Importar para restaurá-lo em qualquer lugar; cada sequência também pode ser baixada como um CSV com suas datas.

O que faz fixar uma sequência?

Fixar marca uma sequência como seu foco atual. Sua sequência fixada pode aparecer nas suas páginas de timer do TomatoTimers, então a corrente que você está construindo fica visível enquanto trabalha — e nos dias em que você ainda não fez check-in, ela está lá para lembrar você.
